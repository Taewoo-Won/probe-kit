# 결선 모의 과제 — HBM 적층 라인

> 연습용 가상 과제입니다. 데이터는 만들어 낸 것이고 실제 회사 · 시험 문제와 관계없습니다.

## 상황

HBM은 D램 다이(칩 한 장)를 12층으로 쌓아 만든다. 다이를 한 층씩 붙이고(본딩), 12층을 다 쌓은 뒤에 **최종 테스트**에서 처음으로 쓸 수 있는지 판정한다.
최종 테스트에서 떨어진 스택은 **붙어 있는 다이 12장을 통째로 버린다.** 다이 한 장 한 장은 이미 검사를 통과한 멀쩡한 칩이다.

현장 엔지니어 메모:
- "불량은 최종 테스트에서 처음 안다. 그때는 이미 12장을 다 썼다."
- "4층 · 8층 · 12층을 붙인 뒤에 휨(warpage)을 재지만, 그 값은 다른 시스템에 쌓여 있어서 거의 안 본다."
- "웨이퍼 가장자리(edge)에서 나온 다이를 쓰면 휨이 커진다는 말이 있는데, 확인해 본 사람은 없다."
- "A라인과 B라인은 같은 장비 모델인데, 체감상 B라인 불량이 더 많다."

여러분에게 익숙한 기술이 이 현장의 오랜 고민을 푸는 열쇠가 될 수 있습니다. 당연하게 여겨 온 방식에 질문을 던지고, AI와 함께 해결책을 만들어 보세요. 정해진 정답은 없습니다.

## 데이터 (`data/`)

| 파일 | 한 줄 = | 칸 |
|---|---|---|
| `stacks.csv` | 스택 하나 (1,600개, 2026-07 ~ 2026-09) | stack_id, lot_id, line(A/B), start_date, n_layers |
| `layer_log.csv` | 스택의 한 층 (스택마다 12줄) | stack_id, layer(1~12), die_wafer_id, die_pos(center/mid/edge), bond_temp_c(본딩 온도), bond_force_n(본딩 압력), warpage_um(휨, 4 · 8 · 12층에서만 잼, 나머지는 빈칸) |
| `final_test.csv` | 스택 하나의 최종 테스트 | stack_id, result(PASS/FAIL), fail_bin(불량 종류) |
